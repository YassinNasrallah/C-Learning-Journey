# C# Learning Journey

This repository contains my C# practice code as I learn the language from the basics. My goal is to build a strong foundation before using C# for game development.

## What I Learned

In this project, I practiced:

* Creating a C# console application.
* Writing my first `Main()` method.
* Displaying text with `Console.WriteLine()`.
* Reading user input with `Console.ReadLine()`.
* Declaring and using variables.
* Understanding basic C# data types:

  * `char` – stores a single character.
  * `string` – stores text.
  * `int` – stores whole numbers.
  * `decimal` – stores high-precision decimal numbers (commonly used for money and prices).
  * `float` – stores decimal numbers used for speed, position, and physics in game development.
* Performing simple arithmetic operations.
* Concatenating strings with variables.

## Example

The program introduces me and calculates the total price of a PlayStation and a game.
